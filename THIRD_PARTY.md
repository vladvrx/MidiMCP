# Third-party foundations

Serum preset schema, mapping and codec are imported from [Celian-mrc/serum-mcp](https://github.com/Celian-mrc/serum-mcp), revision `6c471bb8424f3f06f16f5b9fc5bfab244fd11384`, MIT licensed, copyright 2026 serum-mcp contributors. Its license remains in the installed upstream checkout. MidiMCP does not redistribute commercial preset libraries or plugin binaries.

Other runtime dependencies are installed separately: MCP Python SDK (MIT), NumPy and SciPy (BSD), SoundFile (BSD), Mido (MIT), plus upstream's CBOR2, Pydantic and Zstandard dependencies. Their licenses apply to those packages. Native audio plugins and FL Studio are separately installed user software and retain their vendors' licenses.
